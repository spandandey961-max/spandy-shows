SPANDY SHOWS - MICROSOFT STORE SUBMISSION MATERIALS

Status: preparation complete except account identity, packaged installation and certification checks.
The local preview MSIX uses a placeholder identity. DO NOT upload that preview to Partner Center.

1. Register and verify a Windows developer account at https://partner.microsoft.com/dashboard/
2. Reserve Spandy Shows as an MSIX app. A name reservation is subject to availability.
3. Copy Package/Identity/Name, Package/Identity/Publisher and Package/Properties/PublisherDisplayName from Product identity into identity.json. These are public identifiers, not passwords.
4. Confirm the support contact and review privacy-policy-DRAFT.txt and store-listing.json.
5. Host the approved privacy policy at a publicly accessible URL and enter that URL in Partner Center. A Markdown page in GitHub can be used as a readable public document, subject to Microsoft's acceptance.
6. Run Build-Store.ps1 with the staged app folder, MakeAppx path and identity.json. The build creates a new Store package; the publisher identity must match Partner Center even if its public display name is Spandan.
7. Install and check a signed development package on a clean Windows test device, including fresh launch, each language in Run and Visualize, interactive input, EOF, arguments, generated files, named saves, closing/reopening, uninstall and upgrade. Do not distribute a development signing certificate as a trusted public installer.
8. Run Windows App Certification Kit against the final package. Resolve findings and retain the report. WACK has not been run for this preparation.
9. Create a draft submission. Upload the correctly identified MSIX, current screenshots and logos; complete properties, markets, pricing, age-rating questionnaire, privacy disclosures and runFullTrust justification.
10. Review all statements and submit for Microsoft's certification. Store listing publication and signing depend on approval. Test the Store-delivered app, including compiling and launching a new C program, on a protected separate PC before announcing general availability.

This edition targets Windows 10 version 2004 or later and Windows 11 on Intel/AMD x64. It does not target Windows ARM64, macOS, Linux or Android in this package.
Known limitations remain: bounded recording, slow deep-recursion visualization, and optional libraries not all bundled. Do not describe this edition as supporting every program or every library.
