SPANDY SHOWS — MICROSOFT STORE PREPARATION

CURRENT STATUS: NOT READY TO SUBMIT
The repository contains preparation materials only. No valid Partner Center app identity or submission package is available yet. Do not upload a placeholder-identity package.

1. Register and complete verification for a Windows developer account in Partner Center:
   https://partner.microsoft.com/dashboard/
2. Create an MSIX product and reserve “Spandy Shows” if available.
3. Copy the exact Package/Identity/Name, Package/Identity/Publisher and Package/Properties/PublisherDisplayName from Product identity into identity.json. The display name must be the one Partner Center permits; it cannot be chosen independently for the package.
4. Review and approve privacy-policy-DRAFT.txt, then publish it at a public URL and set that URL in the Store listing. Review store-listing.json and certification-notes.txt for accuracy.
5. Build the latest source and staged desktop bundle from this repository. Install the Windows SDK and use its MakeAppx.exe. From the repository checkout, run store-submission/Build-Store.ps1 with the exact identity values and a staged bundle.
6. Install the resulting MSIX on a clean Windows 10/11 x64 test PC. Test launch, Run and Visualize for all three languages, input and EOF, local saves, generated C executables, upgrade and uninstall. Run Windows App Certification Kit (WACK) against the final package and resolve all findings. WACK has not yet been run for this product.
7. Create the Store submission in Partner Center. Upload the real-identity MSIX and Store artwork/screenshots. Complete product properties, category, markets, pricing, age-rating questionnaire, privacy disclosures and the full-trust capability explanation. The app starts local Python, Java and C tools to execute and visualize code explicitly opened or entered by the user.
8. Review the declarations and submit for Microsoft certification. Do not claim Store availability until Microsoft approves and publishes the listing. Then test the Store-installed build before announcing it.

The target package is Windows 10 version 2004 or later and Windows 11, Intel/AMD x64. This package does not target Windows ARM64, macOS, Linux or Android.

Support: https://github.com/spandandey961-max/spandy-shows/issues
Known limits: visualization is bounded; deep recursion may be slow; some optional libraries and graphical applications are not bundled.
